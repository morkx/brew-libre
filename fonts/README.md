# Fuentes del diseñador de etiquetas

Las usa la pestaña **Etiqueta** de Brew-libre. Van incluidas en la app para que funcionen sin conexión y para incrustarlas en las etiquetas exportadas (PNG y SVG). `label-fonts.js` contiene el subconjunto latino de cada fuente en formato woff2 (codificado en base64), tomado de los paquetes [@fontsource](https://fontsource.org/) publicados en npm.
